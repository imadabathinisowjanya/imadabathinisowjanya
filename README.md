<img src="https://img.shields.io/badge/VIEW%20PROJECT-Repository-0891b2?style=for-the-badge&logo=github"/>

An AI-powered PDF question-answering application built using Retrieval-Augmented Generation.

**Core implementation**
- PDF extraction and overlapping text chunking
- Document embeddings using Nomic Embed Text
- Cosine similarity-based document retrieval
- Context-grounded responses using Llama 3.2
- Interactive Streamlit application with page references
- Pytest-based core functionality testing

**Tech:** Python · Streamlit · Ollama · Llama 3.2 · NumPy · PyPDF

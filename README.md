### 📄 AskMyPDF
#### AI DOCUMENT ASSISTANT

<a href="https://github.com/imadabathinisowjanya/askmypdf">
<img src="https://img.shields.io/badge/EXPLORE_PROJECT-6D28D9?style=for-the-badge&logo=github&logoColor=white"/>
</a>

</div>

An AI-powered PDF question-answering application that uses Retrieval-Augmented Generation to answer questions based on uploaded documents.

**⚙️ Core Implementation**

- PDF text extraction using PyPDF
- Overlapping text chunking
- Document embeddings using Ollama's `nomic-embed-text`
- Cosine similarity-based retrieval using NumPy
- Context-grounded answer generation using Llama 3.2
- Streamlit interface with answers and page references
- Core functionality tested using Pytest

**🧰 Technology Stack**

`Python` `Streamlit` `Ollama` `Llama 3.2` `NumPy` `PyPDF` `RAG` `Pytest`
